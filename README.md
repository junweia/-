# 自动点击器 Pro 2.0

这是 Android Studio 项目源码，不是已编译 APK。

## 功能
- 深色科技风中文界面
- 多点坐标：每行填写一个 `X,Y`
- 按顺序循环点击所有坐标
- 点击间隔（最低 100ms）
- 指定总点击次数或持续运行
- 可拖动悬浮控制面板
- 开始、暂停、继续、停止
- 在本机保存当前脚本配置（SharedPreferences）
- 无网络权限；不读取屏幕内容、不上传数据

## 构建
使用 Android Studio 打开项目，安装 Android SDK Platform 36，然后选择：
Build > Build Bundle(s) / APK(s) > Build APK(s)

## 首次运行
1. 安装 APK。
2. 在应用中打开系统无障碍设置，主动启用“自动点击器 Pro”。
3. 授予悬浮窗权限。
4. 输入坐标、间隔、次数并启动控制面板。

坐标以屏幕左上角为原点，单位为屏幕像素。请先在无风险的测试界面验证坐标。不同手机的分辨率和显示缩放可能影响坐标。
请只在你有权操作且允许自动化的应用中使用；不要用于绕过服务规则或进行购买、交易等敏感操作。
